# Источник фильмов

Для каталога используется бесплатный план TMDB API. Через него получаем названия, описания, жанры, актёров, постеры, фоновые изображения, трейлеры и рейтинг TMDB. Данные запрашиваются через backend и сохраняются в локальной базе для кэширования.

Пока проект остаётся некоммерческим, API можно использовать бесплатно. В интерфейсе необходимо указать TMDB как источник, разместить их логотип и уведомление о том, что проект не одобрен и не сертифицирован TMDB. Если появится реклама, подписка или другая монетизация, потребуется согласовать коммерческую лицензию.

На сайте за основу рейтинга тоже будет выступать рейтинг TMDB

## Технические решения

Кешируем частозапрашиваемые данные в локальной базе для кэширования. Это позволяет уменьшить нагрузку на сервер и ускорить запросы к базе данных.

В апи есть так называемые Задники. Их будем использовать в рекомендациях на заднем фоне вместо тейлера. Они будут переодически сменяться.
