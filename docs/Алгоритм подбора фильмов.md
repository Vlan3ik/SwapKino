# Алгоритм рекомендаций SwapKino

## Концепция

TMDB используется для получения фильмов и метаданных. SwapKino самостоятельно:

1. строит профиль интересов пользователя;
2. определяет порядок тематических подборок;
3. получает для них кандидатов из TMDB;
4. ранжирует, фильтрует и перемешивает фильмы.

## Данные пользователя

Хранить каждое действие:

```text
Rating 1–10
SwipeRight
SwipeLeft
Favorite
Watched
NotInterested
Impression
```

Начальные веса:

```text
Rating 9–10       +3.0
Rating 8          +2.0
Rating 7          +1.0
Rating 6           0.0
Rating 1–5        -2.0
Favorite          +2.0
SwipeRight        +1.0
SwipeLeft         -1.2
NotInterested     -3.0
Watched            0.0
```

`Watched` только исключает фильм из будущей выдачи. Сам просмотр не означает, что фильм понравился.

Для свайпов применять временное затухание:

```text
effectiveWeight = actionWeight × exp(-daysPassed / 180)
```

Для импортированных оценок Кинопоиска затухание не применять.


## Профиль пользователя

По действиям рассчитываются словари предпочтений:

```text
GenreScore[tmdbGenreId]
KeywordScore[tmdbKeywordId]
DirectorScore[tmdbPersonId]
ActorScore[tmdbPersonId]
LanguageScore[languageCode]
DecadeScore[decade]
```

Вклад действия распределяется между признаками фильма:

```text
genreContribution = effectiveWeight / genreCount
keywordContribution = effectiveWeight / sqrt(keywordCount)
```

Учитывать одного режиссёра и не более пяти первых актёров.

Итоговые значения нормализовать:

```text
normalizedScore = tanh(totalScore / 4)
```

Диапазон результата: `-1..1`.


## Тематические подборки

Тематики задаются конфигурацией:

```csharp
public sealed record RecommendationTheme(
    string Id,
    string Title,
    int[] GenreIds,
    int[] BoostGenreIds,
    int[] KeywordIds,
    int[] ExcludedGenreIds,
    double MinVoteAverage,
    int MinVoteCount,
    int? MinRuntime,
    int? MaxRuntime,
    int? ReleaseYearFrom,
    int? PreferredHourFrom,
    int? PreferredHourTo
);
```

Примеры:

```text
horror-night
detective-evening
light-comedies
maximum-action
sci-fi-worlds
family-evening
romantic-evening
strong-dramas
modern-animation
proven-classics
new-releases
something-new
```

Хранить конкретные TMDB genre ID и keyword ID. Не выполнять `search/keyword` при каждом запросе.


## Ранжирование тематик

Для каждой тематики:

```text
themeScore =
    0.60 × genreAffinity
  + 0.25 × keywordAffinity
  + 0.10 × recentActivity
  + 0.05 × contextBonus
```

`genreAffinity` — средневзвешенное значение пользовательских `GenreScore` для жанров тематики.

Контекст времени даёт только небольшой бонус. Например, `horror-night` получает бонус после 20:00, но не поднимается наверх, если пользователь не любит ужасы.

Выбрать 5–7 тематик с максимальным `themeScore`.


## Получение кандидатов из TMDB

Использовать три источника.

### От любимых фильмов

Выбрать до 10 фильмов с максимальным положительным весом:

```http
GET /movie/{tmdbId}/recommendations
GET /movie/{tmdbId}/similar
```

### Для конкретной тематики

```http
GET /discover/movie
```

Передавать:

```text
with_genres
with_keywords
without_genres
vote_average.gte
vote_count.gte
with_runtime.gte
with_runtime.lte
primary_release_date.gte
with_original_language
sort_by=popularity.desc
include_adult=false
```

Для каждой тематики загружать 2–5 страниц.

Все результаты объединять по `tmdbId`.


## Загрузка метаданных

Для новых кандидатов:

```http
GET /movie/{id}?append_to_response=keywords,credits,release_dates,watch/providers
```

Сохранять локальный `MovieSnapshot`:

```text
TmdbId
Title
ReleaseDate
Runtime
GenreIds
KeywordIds
DirectorId
ActorIds
Language
CollectionId
VoteAverage
VoteCount
Popularity
PosterPath
BackdropPath
LastSyncedAt
```

Не загружать details повторно, пока snapshot не устарел.


## Ранжирование фильмов

```text
movieScore =
    0.30 × sourceScore
  + 0.30 × profileMatch
  + 0.25 × themeMatch
  + 0.15 × qualityScore
```

### Source score

```text
/recommendations: seedWeight × 1.0 / sqrt(position + 1)
/similar:         seedWeight × 0.7 / sqrt(position + 1)
/discover:                     0.4 / sqrt(position + 1)
```

Если фильм пришёл от нескольких seeds, вклады суммируются:

```text
sourceScore = 1 - exp(-sum)
```

### Profile match

```text
0.55 × genreMatch
+ 0.25 × keywordMatch
+ 0.10 × directorMatch
+ 0.05 × actorMatch
+ 0.05 × languageAndDecadeMatch
```

### Theme match

Проверяет соответствие фильма жанрам и keywords текущей подборки.

### Quality score

Использовать байесовскую корректировку рейтинга:

```text
quality =
    voteCount / (voteCount + 200) × voteAverage
  + 200 / (voteCount + 200) × 6.5
```


## Фильтрация

Полностью исключать:

```text
просмотренные фильмы;
SwipeLeft и NotInterested;
фильмы без постера;
adult-контент;
недавно показанные фильмы;
фильмы из другой подборки текущей ленты;
фильмы, нарушающие ограничения тематики.
```

`Impression` хранить с `userId`, `tmdbId`, `themeId`, `position`, `shownAt`.


## Разнообразие

После сортировки применять reranking:

```text
finalScore =
    0.80 × movieScore
  - 0.20 × similarityToAlreadySelected
```

Ограничения:

```text
не более 2 фильмов одной коллекции;
не более 2 фильмов одного режиссёра;
не более 3 фильмов с одинаковым набором жанров;
один фильм только в одной подборке;
10% фильмов — исследование соседних жанров.
```


## Холодный старт

Если действий меньше пяти:

```text
50% — популярные фильмы TMDB;
50% — фильмы выбранных пользователем жанров.
```

После пяти действий постепенно включать персональный `profileMatch`.


## Кэширование

```text
TMDB genres              7 дней
TMDB movie details       7 дней
similar/recommendations  24 часа
discover results         4 часа
user recommendation feed 30 минут
```

Кэш пользовательской ленты сбрасывать после оценки, свайпа, избранного, импорта Кинопоиска или отметки просмотра.
