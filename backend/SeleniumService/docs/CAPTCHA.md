# Безопасный CAPTCHA-flow

## Что делает сервис

1. Selenium открывает публичный профиль.
2. Сервис проверяет URL, title/page source и текущий адрес на признаки CAPTCHA/SSO.
3. При обнаружении challenge браузер делает PNG-скриншот.
4. API возвращает `409` с кодом `CAPTCHA_REQUIRED`, адресом страницы и скриншотом в base64.
5. Сервис не возвращает cookies, local storage, HTML страницы, iframe-содержимое или токены.
6. Без успешного прохождения challenge импорт не считается завершённым.

Сервис хранит короткоживущую Selenium-сессию в памяти и возвращает `session_id`. После ручного прохождения challenge вызывающий backend вызывает `/api/v1/kinopoisk/captcha/{session_id}/resume`. Для headless-контейнера нужен защищённый VNC/noVNC-канал к тому же Chrome-контексту; просто открыть CAPTCHA в другом браузере нельзя.

## Почему нельзя принять CAPTCHA как обычный текст

Yandex SmartCaptcha может показывать checkbox, slider или дополнительную картинку/текстовую задачу. Результатом является токен, который ограничен по времени и используется один раз. Он связан с пользовательским браузерным контекстом и проверяется сервером Yandex. Поэтому нельзя надёжно реализовать универсальный контракт вида `captcha_answer: string`.

## Безопасный способ продолжения

Для ручного продолжения нужен тот же браузерный контекст:

- headed Chrome на машине пользователя;
- удалённый браузер через VNC/noVNC с авторизацией;
- либо отдельный UI-адаптер, который управляет жизненным циклом Selenium-сессии.

После прохождения challenge сервис должен сам обнаружить, что исходная страница загрузилась, и продолжить обход. Произвольный CAPTCHA-токен от клиента принимать нельзя.

## Риски и меры

| Риск | Мера |
|---|---|
| Утечка cookies/сессии | Не включать cookies, storage и HTML в API-ответ |
| Повторное использование токена | Не сохранять и не принимать токены в сервисе |
| Доступ к скриншоту посторонних | В production добавить auth на endpoint и TTL ответа |
| Зависание Chrome | Ограничить TTL сессии и гарантированно вызывать `quit()` |
| Массовые запросы | Rate limit и очередь на один профиль/IP |
| Подмена домена | Принимать только `www.kinopoisk.ru` и `kinopoisk.ru` |

Источник правил валидации: официальная документация [Yandex SmartCaptcha](https://yandex.cloud/en/docs/smartcaptcha/concepts/validation).
