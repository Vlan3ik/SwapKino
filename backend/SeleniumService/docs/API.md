# API-контракт SeleniumService

Документ предназначен для интеграции с основным SwapKino backend.

## Base URL

Локально: `http://localhost:8081`.

В Docker Compose другой контейнер обращается к сервису по имени `http://selenium-service:8081`.

## Импорт оценок

```http
POST /api/v1/kinopoisk/ratings
Content-Type: application/json
```

Request:

```json
{
  "profile_url": "https://www.kinopoisk.ru/user/36830857/",
  "include_unrated": true
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|:---:|---|
| `profile_url` | URL | да | Публичная ссылка на профиль Кинопоиска |
| `include_unrated` | boolean | нет | Возвращать просмотренные элементы без оценки, по умолчанию `true` |

Response `200` содержит `total`, `rated`, `unrated` и массив `items`. Элемент массива имеет поля `title`, `year`, `genres`, `rating`, `kind`, `kinopoisk_url` и `page`.

`rating` может быть `null`, если произведение просмотрено, но не оценено. `kind` принимает `film` или `series`.

## Обработка ошибок

`409`:

```json
{
  "detail": {
    "code": "CAPTCHA_REQUIRED",
    "message": "Кинопоиск запросил CAPTCHA или авторизацию"
  }
}
```

В расширенном ответе сервис также возвращает `page_url`, `screenshot_base64`, `screenshot_mime_type`, `expires_in_seconds` и `action=manual_interaction_required`. Скриншот предназначен только для отображения оператору/пользователю.

Сервис не возвращает cookies, исходный HTML, iframe-содержимое или CAPTCHA-токен. Скриншот не является способом решить CAPTCHA автоматически. Для продолжения потребуется тот же живой браузерный контекст и интерактивный UI (например, выделенный browser/VNC-канал); передача ответа CAPTCHA как произвольной строки в этот API не поддерживается.

По документации Yandex токен одноразовый, имеет ограниченный срок действия и проверяется через официальный endpoint в пользовательском контексте. Поэтому токен нельзя кэшировать, переиспользовать или принимать от непроверенного клиента.

## Продолжение после CAPTCHA

Если сервис вернул `session_id`, после ручного прохождения challenge в том же браузерном окне вызовите:

```http
POST /api/v1/kinopoisk/captcha/{session_id}/resume
```

Сессия хранится только в памяти процесса и действует 5 минут. Если сервис запущен в headless-режиме, пользователю нужен отдельный VNC/noVNC или другой интерактивный канал к тому же Chrome-контексту. Нельзя проходить CAPTCHA в другом браузере и передавать в API её токен.

`422` означает ошибку входной ссылки. `502` означает техническую ошибку браузера/целевого сайта и может быть повторён с backoff.
